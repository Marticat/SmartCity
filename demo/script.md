# Запись демонстрации — 2 минуты 30 секунд

Запустить production приложение на `http://127.0.0.1:8000`. Используется настоящий локальный OSM snapshot и текущий статус поиска. Не скрывайте баннер ограниченного режима. Если включены fixtures или фиксированное время, подпишите их на экране; штатная запись использует реальные данные.

| Время | Действие в интерфейсе | Текст за кадром |
|---|---|---|
| 0:00–0:15 | Показать интерфейс, открыть локальный поиск ориентиров | «QADAM помогает выбрать занятие рядом, когда есть 30–90 минут». |
| 0:15–0:50 | Выбрать EXPO, 60 минут, обычную прогулку и отправить запрос | «Указываем место и время. Приложение ищет по реальным данным, учитывая расстояние и ограничения». |
| 0:50–1:15 | Открыть источник первой карточки, нажать «На карте» | «Название и свойства пришли из источника. Оценка посещения и идея занятия обозначены отдельно». |
| 1:15–1:45 | Изменить бюджет до 30 минут, показать новый ответ | «Изменение времени запускает новый расчёт. Без маршрутизатора дистанция подписана как прямая». |
| 1:45–2:15 | Ввести «Кофе с обязательной розеткой», отправить запрос | «Если розетка не подтверждена, место не выдаётся как подходящее. Недостаток данных показан честно». |
| 2:15–2:30 | Показать «Почему эти места» и режим работы | «Данные, ограничения и выполненные проверки доступны в проекте. Полная генерация требует серверного ключа». |

Сценарий автоматической записи: `node demo/record.cjs` после установки browser dependencies и запуска сервера. Проверка кадров: `node demo/verify-video.cjs`. Сохранённый результат — **`QADAM-demo.webm`, 149.4 секунды, 1440×1000, без аудио**. Озвучивание можно сделать по таблице выше. Запись использует реальный интерфейс, настоящий snapshot и normal online map tiles; это не нагрузочный тест. Режим в записи — поиск без генерации, semantic индекс работает. Проверенные кадры показывают реальную карту и честное отсутствие результатов при обязательной розетке.

Запись сделана до финальной коррекции шести неопределённых тегов интернет-доступа и небольшого уточнения ранжирования. В показанном сценарии Wi-Fi не обещается; итоговые тесты и метрики относятся к последней версии данных. Для записи ровно последней версии выполните те же команды повторно.

## YouTube

**Название:** QADAM — прогулка по Астане под твоё время | Smart City demo

**Описание:**

QADAM — прототип помощника для прогулок, кофе и занятий с ребёнком в Астане. Автоматический сбор OpenStreetMap, гибридный поиск, строгие ограничения и проверяемые источники. В записи показан фактический режим приложения; при отсутствии LLM ключа используется явно обозначенный поиск без генерации. Данные: © OpenStreetMap contributors, ODbL 1.0. Время посещения оценочное, прямое расстояние не гарантирует пешеходный маршрут.

**Ручной финальный шаг:** владелец входит в YouTube Studio, загружает локальный WebM, выбирает «Доступ по ссылке», проверяет воспроизведение и сохраняет реальный URL. Авторизация на YouTube не предоставлена; публикация не выполнена.
