# Демонстрация QADAM с Gemini — 2:40

Запустить production приложение на `http://127.0.0.1:8000`. Запись использует настоящий локальный snapshot, реальный API и обычные запросы карты. Ответы не перехватываются и не подменяются. Начальный ответ должен пройти в режиме RAG; иначе скрипт останавливается. Следующие сцены сохраняют фактический режим приложения, включая резервный поиск и отсутствие совпадений.

| Эпизод | Действие | Смысл |
|---|---|---|
| Ввод | Выбрать реальный EXPO, 60 минут, прогулку | Контекст места и времени |
| 1 / 4 | Показать результат, раскрыть сведения, выделить на карте | Названия и свойства имеют источники, неизвестное не обещается |
| 2 / 4 | Сменить 60 минут на 30 | Новый подбор выполняется сервером |
| 3 / 4 | Выбрать 120 минут и запросить интерактивный музей | Официальное описание подтверждает конкретный интерес; генерация для этого не имитируется |
| 4 / 4 | Попросить кофе с обязательной розеткой | При отсутствии подтверждения условие не выполняется |
| Финал | Раскрыть объяснение поиска | Видны ограничения и фактически выполненная обработка |

Точные моменты семи экранных подписей находятся в `demo/recording.json` (`captions[].at_seconds`). Подписи добавлены только для записи, не меняют данные приложения. Скрипт останавливает запись, если музей в реальном ответе не имеет подтверждённой интерактивности и официального описания.

## Воспроизведение записи

```sh
node demo/record.cjs
node demo/verify-video.cjs
```

Нужны запущенное приложение, установленные frontend dependencies и Chromium (`cd frontend`, затем `npx playwright install chromium`). Сырой результат — `demo/QADAM-demo.webm`, без звука. Длительность и размеры фиксируются в `demo/video-check.json`; кадры сохранены отдельно для визуальной проверки.

Версия для просмотра и загрузки — `demo/QADAM-demo-narrated.mp4`. Она содержит **синтетическую русскую озвучку Microsoft Irina Desktop**, а не речь участника команды. Голос создаётся локально на Windows, внешние провайдеры не вызываются. Субтитры: `demo/QADAM-ru.srt`, текст: `demo/narration.json`, проверка синхронизации: `demo/narration-check.json`. Озвучка соответствует новой записи с настоящими ответами Gemini. При отсутствии совпадений модель не вызывается.

Повторная сборка после `record.cjs` и `verify-video.cjs`:

```powershell
.\.venv\Scripts\python.exe -m pip install imageio-ffmpeg==0.6.0
powershell -ExecutionPolicy Bypass -File demo/narrate.ps1
```

Нужен установленный Windows голос Microsoft Irina Desktop. WAV-файлы создаются в `artifacts/narration/` и не входят в репозиторий. На Linux можно выполнить mux через `scripts/build_narrated_demo.py` только при наличии уже подготовленных WAV; сам Windows TTS там недоступен.

## YouTube

**Название:** QADAM — прогулка по Астане под твоё время | Smart City demo

**Описание:**

QADAM — прототип помощника для прогулок, кофе и занятий с ребёнком в Астане. Реальные данные OpenStreetMap, шесть описаний по официальным источникам, гибридный поиск и строгие условия. В записи показан настоящий RAG с Gemini. Пешие маршруты ORS ещё не подключены. Синтетическая русская озвучка — Microsoft Irina. Данные: © OpenStreetMap contributors, ODbL 1.0. Время посещения оценочное, прямое расстояние не гарантирует пешеходный маршрут.

**Шаг владельца:** войти в YouTube Studio, загрузить озвученный MP4 либо исходный WebM, выбрать «Доступ по ссылке», проверить воспроизведение и сохранить реальный URL. Публикация от имени владельца не выполнена.
