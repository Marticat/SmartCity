# Как загрузить демо QADAM на YouTube

Видео уже готово. Перезаписывать его для загрузки не требуется.

## 1. Выбери файл

Загружай **[QADAM-demo-narrated.mp4](QADAM-demo-narrated.mp4)** — 2 минуты 30 секунд, реальная запись приложения с синтетической русской озвучкой Microsoft Irina.

Путь для окна выбора файла Windows:

```text
C:\Users\ARYSLAN Kurmetov\SmartCity\demo\QADAM-demo-narrated.mp4
```

В записи работает гибридный поиск без генерации (`search_only`). Живой вызов Gemini и пешеходные маршруты ORS ещё требуют ключей и проверки. Это объяснено в самом ролике.

## 2. Загрузи

1. Войди в свой канал в [YouTube Studio](https://studio.youtube.com/).
2. Нажми **«Создать» → «Добавить видео»** и выбери MP4 выше.
3. Вставь название и описание из следующих блоков.
4. Укажи аудиторию: для этого технического демо, адресованного жюри, — **«Видео не для детей»**. Язык видео — русский.
5. Для значка можно выбрать предложенный YouTube кадр с интерфейсом.
6. Пройди шаги загрузки и посмотри результаты проверки.
7. В настройках доступа выбери **«Доступ по ссылке»** и сохрани результат.

Порядок загрузки описан в [официальной справке YouTube](https://support.google.com/youtube/answer/57407?hl=ru&co=GENIE.Platform%3DDesktop). Доступ по ссылке позволяет жюри смотреть ролик без отдельного приглашения; любой получивший ссылку также сможет переслать её. [Справка о доступе](https://support.google.com/youtube/answer/157177?hl=ru).

## 3. Название — скопируй целиком

```text
QADAM — прогулка по Астане под твоё время | Smart City demo
```

## 4. Описание — скопируй целиком

```text
QADAM — прототип городского помощника по Астане для задачи НИЦ Smart City.
Есть время. Есть куда пойти.

Пользователь выбирает стартовую точку, время и интересы. Сервис подбирает 1–3 места, объясняет выбор, показывает примерное время посещения, идею занятия и источники данных.

В демо:
• прогулка рядом с EXPO и реальные места на карте;
• изменение бюджета с 60 до 30 минут;
• интерактивный музей с официальным источником;
• честный ответ, когда обязательная розетка не подтверждена.

Данные: 814 POI, автоматически собранных из OpenStreetMap. Для шести мест добавлены описания по официальным источникам. Срез данных — 20 октября 2026 года; покрытие — центральная Астана и район EXPO.

Технологии: FastAPI, React/TypeScript, Leaflet, semantic search multilingual-e5-small + SQLite FTS5.

В этой записи показан режим поиска без генерации (search_only). Интеграция Gemini подготовлена в коде, но живой вызов требует серверного ключа и отдельной проверки. ORS не подключён: расстояния по прямой не гарантируют пешеходный маршрут или время дороги. Время посещения оценочное; неизвестные часы и удобства не выдаются за подтверждённые.

Код, документация и презентация:
https://github.com/Marticat/SmartCity

00:00 QADAM и задача
00:26 Реальные места на карте
00:40 Источники и достоверность
01:06 Меняем время прогулки
01:17 Интерактивный музей
01:41 Если розетка обязательна
01:59 Текущий режим и ограничения

Запись показывает настоящее приложение. Русская озвучка синтетическая — Microsoft Irina Desktop.
Данные: © OpenStreetMap contributors, ODbL 1.0.
https://www.openstreetmap.org/copyright

#QADAM #Astana #SmartCity
```

Таймкоды соответствуют готовому MP4. Если перемонтируешь видео, обнови их. Отображение эпизодов зависит от доступности функции на канале; сами таймкоды остаются полезной навигацией. [Справка об эпизодах](https://support.google.com/youtube/answer/9884579?hl=ru).

## 5. Добавь готовые субтитры

В YouTube Studio открой **«Субтитры»**, выбери ролик и русский язык, затем **«Добавить» → «Загрузить файл» → «С временными метками»**. Выбери **[QADAM-ru.srt](QADAM-ru.srt)** и сохрани субтитры. В файле уже есть текст озвучки и синхронизация. [Официальная инструкция](https://support.google.com/youtube/answer/2734796?hl=ru).

```text
C:\Users\ARYSLAN Kurmetov\SmartCity\demo\QADAM-ru.srt
```

## 6. Проверь и отправь

- Дождись обработки видео, открой его и проверь читаемость интерфейса, звук и субтитры.
- Скопируй **ссылку на просмотр ролика**, а не адрес страницы редактирования Studio.
- Открой ссылку в приватном окне браузера: ролик должен воспроизводиться.
- Вставь реальную ссылку в заявку на хакатон и на последний слайд презентации.
- Вместе со ссылкой передай [репозиторий](https://github.com/Marticat/SmartCity), [презентацию PDF](../presentation/QADAM.pdf) и [тестовые сценарии](../docs/test-scenarios.md).

Ролик 2:30 — отдельное демо. Для защиты на 5–7 минут подготовлены [заметки выступающего](../presentation/speaker-notes.md). Полный показ ролика добавит 2:30 к выступлению: используй его отдельно или замени часть рассказа коротким фрагментом.

На момент подготовки инструкции видео ещё не загружено: действительную YouTube-ссылку нужно получить после публикации в своём аккаунте.
