## Граница MVP
Реальные POI Астаны, локальный гибридный поиск, строгие ограничения, 1–3 варианта,
Gemini с проверкой источников и честным fallback, выбор локации, интерактивная карта.
Погода — с отметкой актуальности; без routing key расстояния только по прямой.
Нет аккаунтов, оплаты, выдуманных услуг или обещаний точного времени пути.

## Готовность
Рабочий локальный запуск, проверенный сбор и индекс, тесты backend и browser,
production build, источники на карточках и корректные unknown-значения.
Реальный LLM e2e считается проверенным только после вызова с рабочим ключом.

## Доработка по критериям НИЦ Smart City
- [x] Естественные объяснения и идеи с фактическими слотами, проверкой evidence и отдельным model reviewer.
- [x] Использование сгенерированных why/evidence в публичном ответе, сохранение обязательных оговорок.
- [x] Приватный контекст модели: разрешённые темы и грубые диапазоны расстояния.
- [x] Шесть описаний и варианты названий по официальным страницам, provenance и offline-обогащение.
- [x] Пожелания к тишине/интерактивности, диапазон 1–2 часа и корректное «Wi-Fi не обязателен».
- [x] 120 минут в интерфейсе, планируемые дата/время Астаны, уточнение ночных запросов.
- [x] Устранение старых вариантов автодополнения при вводе новой локации.
- [x] Независимый разговорный evaluation и реальные provider smoke-check команды с redacted receipts.

Разговорный evaluation сохраняет первый неудачный прогон и повтор после исправления.
Автоматическое прохождение проверяемых условий не заменяет оценку полезности человеком.
Маршрут «прогулка, затем кофе» пока не строится как последовательность остановок;
это остаётся ограничением, а не заявленной реализованной функцией.
