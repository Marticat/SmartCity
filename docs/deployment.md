# Размещение

Локальный запуск проверяется по README. Публичный адрес не создан: аккаунт хостинга и домен не предоставлены.

Реалистичный вариант — одна Linux VM с Docker, 2–4 vCPU, 4 GB RAM и 6–10 GB свободного диска. Это стартовая инженерная оценка ресурсов, не нагрузочный benchmark. E5 работает на CPU; модель и индекс подготавливаются до обслуживания запросов.

```sh
test -f .env || cp .env.example .env
# Указать серверные секреты в .env
docker compose build
docker compose run --rm qadam python -m scripts.collect_pois --validate
docker compose run --rm qadam python -m scripts.index_pois
docker compose up -d
docker compose logs --tail=100
curl http://127.0.0.1:8000/health
```

Один Python-контейнер раздаёт API и собранный frontend. Каталог `./data` примонтирован в `/app/data`, поэтому snapshot, SQLite, индекс и модель переживают пересоздание контейнера. Обновлять данные следует отдельной административной командой, не публичным API.

Только публичные `VITE_TILE_URL` и `VITE_TILE_ATTRIBUTION` передаются в frontend build args. Секреты не включаются в сборку. Изменение подложки требует `docker compose build`. При стандартной OSM подложке соблюдайте ограничения провайдера; коммерческую нагрузку планируйте с подходящим поставщиком тайлов.

Для внешнего доступа поставьте HTTPS reverse proxy (например Caddy) перед `127.0.0.1:8000`; настройте размер тела запроса, timeout не короче 35 секунд и ограничение частоты. Генератор имеет собственный общий лимит 25 секунд. Не логируйте POST body и query string поиска локации (`/api/locations/search?q=...`); отключите соответствующие access logs или удаляйте параметры до записи. Закройте прямой порт приложения файрволом; секреты храните вне Git. CORS нужен только для раздельных доменов; единый origin проще для MVP.

Перед обновлением сохраните копию `data/processed`, `data/manifests`, `data/raw` и индекса. Сначала подготовьте новую версию и проверьте checksum; не обновляйте тяжёлую модель во время активного демо. Сломанный внешний сбор должен оставлять предыдущий валидный snapshot.

Статус фактического выполнения Docker build/run и ограничения окружения: [verification.md](verification.md).
