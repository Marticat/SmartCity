# Проверенные сценарии

Статус на 20 октября 2026. Тестовые fixtures изолированы в `tests/`; реальный браузер использует OSM snapshot. Автотесты времени и внешних сервисов детерминированы. «Проверено fixtures» не означает реальный вызов провайдера.

| Сценарий | Ожидание | Проверка / фактический статус |
|---|---|---|
| Прогулка 60 минут у реального ориентира | 1–3 реальных места, источник, география | Пройдено в браузере; semantic + FTS5, search_only |
| Кофе, обязательная розетка | Unknown не проходит условие | Unit + API fixtures + frozen real-data strict case: 0 результатов |
| Розетка не нужна | Не добавлять требование | Пройдено; найденный дефект исправлен |
| Wi-Fi не обязателен | Не превращать необязательное свойство в фильтр | Первый разговорный прогон обнаружил ошибку; после исправления точный исходный запрос проходит |
| С ребёнком, 45 минут, ветер 45 км/ч | Подтверждённое indoor выше | Пройдено с фиксированным прогнозом fixture |
| Только помещение | Не выводить indoor из категории | Все обязательные атрибуты проверены unit; реальный preset в HTTP smoke |
| Музей без часов | Unknown | Unit + API fixture пройдены |
| Закрывается до завершения визита | Не считать доступным | Unit фиксированный вторник 12:00, визит 30 мин, закрытие 12:15: closed |
| Пересекающиеся часы с исключением | Не обещать open | Пройдено; «Mo-Fr 09-18; Mo off» даёт unknown |
| Не кафе, хочу парк | Ни одного кафе | Unit, API fixture, frozen real-data case пройдены |
| 20 минут и возврат | Учитывать обратную дорогу | Unit lower-bound пройден; гарантия реального пути не заявлена |
| 5 минут в тексте | Не расширять молча | Пройдено; короткое уточнение |
| Река / неизвестный пеший маршрут | Не рисовать прямую как готовый путь | Adapter failure + API straight_line; время дороги null |
| Нет wheelchair evidence | Не обещать доступность | Unit strict filter пройден |
| Геолокация не предоставлена | Ручная локация доступна | Браузер пройден без геолокации; ручной ввод работает |
| Точка вне области | Понятное ограничение | API fixture пройден |
| Overpass частично ответил | Сохранить snapshot | 3 mock попытки, прежний snapshot не изменился |
| LLM не настроена | Search-only, реальный индекс | Реальный endpoint пройден; live генерация открыта |
| Routing недоступен | Null вместо выдуманного пути | Adapter fixture и реальный запуск без ORS ключа |
| Секретная крыша ночью | Публичные альтернативы / уточнение | Unit parsing пройден |
| Два часа до вылета | Не гарантировать рейс | Unit уточнение пройдено |
| POI с «игнорируй инструкции» | Сохранить как данные | Нормализация fixture + валидация слотов/evidence; live prompt injection не проверен без LLM |
| LLM вернула чужой ID | Отклонить | Unit grounding пройден |
| Повторная нормализация | Не плодить дубли | Source ID/spatial/category unit; cached normalization CLI |
| Быстрая смена фильтров | Старый ответ не заменяет новый | Пройдено `verify-resilience.cjs` с изолированными тестовыми ответами; не использовалось для demo |
| Сетевая ошибка | Сообщение и повторный запрос | Пройдено `verify-resilience.cjs` |
| Выбор точки на карте | Координаты уходят в POST body | Пройдено `verify-resilience.cjs` |
| Mobile 390 px | Нет горизонтального скролла | Браузер пройден, список/карта |
| Два часа / 1–2 часа | Корректный бюджет и видимый конфликт с фильтром | Unit natural-hour cases; разговорный API benchmark |
| Тишина / интерактивность | Unknown не превращается в факт | Unit required preferences; отдельные caveats в реальных сценариях |
| Ночь без даты и времени | Уточнение времени визита | Unit word forms и conversation case |
| Ночь с явным +05:00 | Дата, прогноз, расписание для визита | Conversation case и браузеры с timezone Honolulu/Berlin; одинаковое время Астаны |
| Генератор свободно перефразировал факт | Слоты подставлены, evidence совпадает | Unit slot renderer и отдельный semantic-review fixture |
| Reviewer не согласен с объяснением | Ограниченный retry, затем шаблон | Пройдено через mock provider; не заявляется live Gemini |

Автосценарии ищут свойства ответа, а не полное совпадение генерируемой фразы. Fixtures не участвуют в benchmark и демо.

Последняя независимая оценка: 17/17 объективных кейсов на реальном API; первый результат 16/17 сохранён для аудита исправления. Человеческие баллы полезности ещё не выставлены. Методы, ограничения и пути receipts: [verification.md](verification.md).
