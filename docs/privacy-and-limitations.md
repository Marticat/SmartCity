# Приватность и границы

Приложение использует введённый запрос, выбранную точку, время и фильтры для текущего подбора. Разрешение геолокации необязательно: точку можно выбрать вручную или найти по локальным ориентирам.

Точная позиция передаётся серверу в JSON body, а не query string. История запросов и пользовательские аккаунты в MVP не сохраняются. Не включайте логирование тел запросов на reverse proxy. Серверные ключи хранятся в `.env`/секретах окружения; переменные `VITE_*` публичны.

Внешние обращения:

- Gemini получает распознанные категории/предпочтения и разрешённые объяснения, ID, evidence и идеи выбранных POI, если настроен ключ. Исходный текст запроса и точная пользовательская позиция в текущем адаптере не передаются модели. Перед публичным запуском проверьте условия хранения данных выбранного тарифа.
- Open-Meteo получает округлённую точку района для погоды.
- При включённом openrouteservice провайдер получает координаты маршрута.
- Сервер тайлов карты видит IP браузера и запрошенные тайлы; браузер загружает их напрямую.
- Overpass используется при обновлении набора данных, а не для пользовательских запросов.

В данных OSM возможны ошибки, неполнота и задержки обновления. Время загрузки нашей системой не означает подтверждения сведений заведением. Отсутствующие часы, Wi-Fi, розетки и доступность остаются неизвестными. Тег доступности здания не подтверждает весь путь.

Длительность посещения — продуктовый ориентир. Прямое расстояние не учитывает реки, заборы и входы. Без проверенного пешеходного маршрута приложение не гарантирует, что прогулка уложится в бюджет. Погодные пороги — продуктовые предпочтения, не медицинская оценка безопасности.

QADAM не рекомендует проникновение на крыши, стройки или закрытую территорию. Запрос перед вылетом требует дополнительного контекста; сервис не гарантирует возвращение к рейсу. Пользователь принимает решение с учётом обстановки на месте.

Коммерческий запуск потребует проверки лицензий данных и сервисов, настройки HTTPS, ограничения запросов, политики хранения и пользовательского уведомления. Это инженерные границы прототипа, а не юридическое заключение.
