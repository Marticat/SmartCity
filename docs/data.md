## Воспроизводимость

Из корня, после установки `requirements.txt`:

```sh
python -m scripts.collect_pois --refresh
python -m scripts.collect_landmarks
python -m scripts.collect_pois --normalize-only
python -m scripts.collect_pois --validate
python -m scripts.index_pois
```

Без `--refresh` используется сохранённый snapshot. Не запускайте многократные сетевые сборы ради проверки: нормализацию и валидацию можно повторять offline. При сети с ограничениями используйте поставляемый реальный snapshot. `--lexical-only` у индексатора — только явно ограниченный текстовый режим.

- `data/raw/overpass_astana.json`: исходный разрешённый snapshot.
- `data/processed/pois.json`: типизированные нормализованные POI.
- `data/processed/quality.json`: числа качества.
- `data/manifests/collection.json`: запрос, область, дата, причины отбраковки, checksum.
- `data/manifests/index.json`: версия модели, соответствие ID и векторов, checksum.
- `data/index/`: SQLite FTS5 и embeddings, воспроизводимо строятся.
- `data/models/`: локальная модель, скачивается при подготовке, не в запросе.

Дополнительные исходные ориентиры (EXPO, Mega Silk Way, Бәйтерек, Ботаникалық бақ и ЭКСПО-2017) собраны `scripts.collect_landmarks` отдельным запросом, 5 записей от `2026-10-20T08:43:07Z`. Они не подмешиваются в 814 рекомендационных POI и не меняют checksum frozen benchmark.

Checksum нормализованного набора: `4db3250364d8808631d559fd381318fa730d36dda331734407d958b5efc4ced7`.

Для node берётся исходная точка, для way/relation — центр геометрии с `coordinate_kind=polygon_center`. Центр не называется входом. `attributes` используют `true/false/null`, `field_provenance` связывает известное поле со ссылкой и временем. Собственные имена не переводятся выдуманным переводом.

Источник и дата обновления каждого объекта отделены от `collected_at`. Сборщик использует идентифицирующий User-Agent, timeout и ограниченные повторы. Частичный/пустой ответ не должен заменять валидный snapshot. Входы, часы и свойства требуют дальнейшего полевого уточнения.
