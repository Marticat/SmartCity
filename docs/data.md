Известно означает true или false. 808 описаний детерминированно выведены из тегов. Ещё 6 — короткие проверенные резюме официальных страниц: Национального музея, Ботанического сада, Astana Ballet, Astana Opera, арки «Мәңгілік Ел» и моста «Атырау». Цена, рейтинг, тишина, очереди и текущие события не добавляются. Наличие кафе не доказывает помещение, Wi-Fi или розетку.

Описания и дополнительные свойства хранятся в `data/enrichment/official-pois.json`. Для каждого факта записаны URL, название источника и дата просмотра; OSM остаётся источником координат и идентичности объекта. Это редакторское обогащение поверх автоматического сбора, а не автоматическое извлечение фактов с сайтов. Полные страницы и фотографии не копируются.

Из тех же источников добавлены проверенные варианты названий, например «Национальный музей». Поиск отправной точки сначала показывает совпадения имён и алиасов, затем совпадения текста описаний. Это позволяет искать объект по русскому названию, даже когда основное имя OSM записано на казахском.

У [Национального музея](https://nmrk.kz/ru/structure/exhibition-activities/) подтверждены внутренние залы и сенсорные информационные устройства. В описание также включено сообщение сайта о закрытом на обновление зале «Астана» на дату проверки. Это не гарантия работы каждого устройства или доступности остальных залов сегодня. Ещё одно подтверждение indoor относится к явно описанному зрительному залу [Astana Ballet](https://astanaballet.com/ru/pages/o-teatre).

При нормализации запись обогащения применяется только при совпадении ID, имени и категории; конфликт с известным свойством OSM требует проверки. Резюме старше 180 дней или с будущей датой не применяется при следующей нормализации. Уже собранный snapshot остаётся датированным снимком: его нужно обновлять, а не считать живой проверкой.

## Воспроизводимость

Из корня, после установки `requirements.txt`:

```sh
python -m scripts.collect_pois --refresh
python -m scripts.collect_landmarks
python -m scripts.collect_pois --normalize-only
python -m scripts.collect_pois --validate
python -m scripts.index_pois
python -m scripts.check_sources
```

Без `--refresh` используется сохранённый snapshot. Не запускайте многократные сетевые сборы ради проверки: нормализацию и валидацию можно повторять offline. При сети с ограничениями используйте поставляемый реальный snapshot. `--lexical-only` у индексатора — только явно ограниченный текстовый режим.

- `data/raw/overpass_astana.json`: исходный разрешённый snapshot.
- `data/processed/pois.json`: типизированные нормализованные POI.
- `data/processed/quality.json`: числа качества.
- `data/manifests/collection.json`: запрос, область, дата, причины отбраковки, checksum.
- `data/manifests/index.json`: версия модели, соответствие ID и векторов, checksum.
- `data/enrichment/official-pois.json`: 6 проверенных резюме с источниками и точной привязкой к POI.
- `data/manifests/source-check.json`: проверка доступности страниц и контрольных слов, не подтверждение всех фактов.
- `data/index/`: SQLite FTS5 и embeddings, воспроизводимо строятся.
- `data/models/`: локальная модель, скачивается при подготовке, не в запросе.

Дополнительные исходные ориентиры (EXPO, Mega Silk Way, Бәйтерек, Ботаникалық бақ и ЭКСПО-2017) собраны `scripts.collect_landmarks` отдельным запросом, 5 записей от `2026-10-20T08:43:07Z`. Они не подмешиваются в 814 рекомендационных POI и не меняют checksum frozen benchmark.

Checksum обогащённого набора: `73d19201cb01a2eaaea87661edad69d694ed13a4eb797b5423678659bb59e74d`.
Предыдущий checksum `4db3250364d8808631d559fd381318fa730d36dda331734407d958b5efc4ced7` сохранён в исходном benchmark; метки того набора не менялись.

`check_sources` запрашивает только шесть страниц из фиксированного списка HTTPS-доменов, проверяет доступность и контрольные слова, сохраняет хеш текста. Он не продлевает дату редакторской проверки и не доказывает актуальность каждого утверждения. При изменении страницы сначала перепроверьте резюме, затем обновите `reviewed_at`, нормализуйте данные и перестройте индекс.

Для node берётся исходная точка, для way/relation — центр геометрии с `coordinate_kind=polygon_center`. Центр не называется входом. `attributes` используют `true/false/null`, `field_provenance` связывает известное поле со ссылкой и временем. Собственные имена не переводятся выдуманным переводом.

Источник и дата обновления каждого объекта отделены от `collected_at`. Сборщик использует идентифицирующий User-Agent, timeout и ограниченные повторы. Частичный/пустой ответ не должен заменять валидный snapshot. Входы, часы и свойства требуют дальнейшего полевого уточнения.
